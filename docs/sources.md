# 공식·공개 데이터 소스

상태와 canonical 구현 경로는 `ssot/registry/apis.json`에서 관리한다. 이 문서는
부모 제품이 사용하는 주요 공식·공개 출처의 사람이 읽는 인덱스다.

- 학교알리미 Open API: https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_m0.do
- 유치원알리미 Open API: https://e-childschoolinfo.moe.go.kr/openApi/openApiIntro.do
- NCIC 국가교육과정정보센터: https://ncic.re.kr
- 학생평가지원포털: https://stas.moe.go.kr
- 에듀넷 티클리어: https://www.edunet.net
- 공공데이터포털: https://www.data.go.kr

- 복지로: https://www.bokjiro.go.kr
- 정부24: https://www.gov.kr
- 응급의료포털 E-Gen: https://www.e-gen.or.kr
- 공공데이터포털 어린이집·놀이시설·스쿨존·응급의료 데이터:
  https://www.data.go.kr

라이브 결과는 출처 URL과 확인 날짜를 함께 기록한다. 접근 승인이나 카탈로그
발견을 구현·배포 완료로 간주하지 않는다.
