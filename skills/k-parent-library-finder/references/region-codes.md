# 도서관 정보나루 지역코드 (시·도)

`region` 파라미터에 쓰는 2자리 코드. 출처: 도서관 정보나루 Open API 활용방법(https://www.data4library.kr/apiUtilization), 아래 검증 참고.
구·군 단위 `dtl_region`(5자리)은 활용방법 페이지의 세부지역 코드표를 본다.

| 코드 | 지역 | 코드 | 지역 |
| --- | --- | --- | --- |
| 11 | 서울 | 31 | 경기 |
| 21 | 부산 | 32 | 강원 |
| 22 | 대구 | 33 | 충북 |
| 23 | 인천 | 34 | 충남 |
| 24 | 광주 | 35 | 전북 |
| 25 | 대전 | 36 | 전남 |
| 26 | 울산 | 37 | 경북 |
| 29 | 세종 | 38 | 경남 |
|  |  | 39 | 제주 |

2026-10-27에 17개 코드 모두 `library-search`로 조회해, 돌아온 도서관 주소의 시·도가 표와 일치함을 확인했다.
