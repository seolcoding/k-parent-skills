# 부모 지식 도우미

## 핵심 동작

부모가 묻는 일반적인 지식, 생활 판단, 학교/학원/육아 관련 설명을 출처와 현재성에 유의해 답하는 절차를 정의한다.

## 사용 시점

- "이게 무슨 뜻이야?"
- "초등학교 준비물 기준 알려줘"
- "아이랑 이런 상황이면 어떻게 판단하지?"
- "요즘 부모들이 많이 챙기는 게 뭐야?"

## 전형적 흐름

### 1. 질문 위험도 분류

- 일반 생활 지식
- 학교/행정 절차
- 건강/의료/심리 고위험
- 법/금융/개인정보 고위험

### 2. 출처 기준 답변

현재성이 중요한 내용은 출처와 날짜를 확인한다. 추정, 후기, 공식정보를 분리한다.

### 3. 부모 다음 행동 명확화

답변은 다음 행동, 확인할 곳, 주의할 점으로 정리한다.

## 출력 형식

- 아이 나이/학년 또는 적용 대상
- 지역/기관 맥락이 있으면 명시
- 날짜 범위, 현재성 여부, 확인 기준일
- 공식 출처 URL 또는 참고 출처와 source freshness
- 비용, 준비물, 필요 서류, 마감일이 있으면 분리
- 신청/예약/로그인/본인인증 필요 여부
- 공식 정보, 추정, 후기성 정보 구분
- 부모의 다음 행동

## 완료 조건

- 고위험 영역을 구분했다.
- 현재성이 필요한 정보는 확인 기준을 표시했다.
- 부모가 다음 행동을 알 수 있다.
