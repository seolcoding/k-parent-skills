## 2. 라이선스 판단

- **교육부·국가교육위원회 고시 원문(고시문+별책)은 저작권법 제7조 제2호(국가 또는 지방자치단체의 고시·공고·훈령 그 밖에 이와 유사한 것)에 따라 저작권 보호 대상이 아니며 자유이용 가능하다.** 성취기준 문장은 고시 별책의 일부이므로 상업 앱 번들에 안전하다. 본 JSON은 이 고시 원문에서만 추출했다.
- **NCIC(ncic.re.kr) 주의**: robots.txt가 `Disallow: /`로 **자동 수집 금지**. 본 작업에서도 NCIC에는 자동 요청을 보내지 않았고, 원문 PDF는 사람이 브라우저로 수동 다운로드했다. 재수집 시에도 동일하게 할 것.
- **KICE 저작물 주의**: NCIC 저작권 정책상 KICE 제작물(성취수준·평가기준·해설 자료 등)은 **공공누리 제2유형(출처표시·비상업·2차적저작물 허용)** — 상업 앱 번들 불가, 참고용만. 예: 교육청 게시판에 도는 "2022 개정 교육과정에 따른 성취수준" HWP는 KICE 자료이므로 본 번들에 포함하지 않았다.
- 참고: 국가교육위원회(ne.go.kr)가 직접 작성·공표한 저작물은 공공누리 제1유형(출처표시, 상업이용·변경 허용) 고지가 있으나, 본 번들의 근거는 그보다 강한 저작권법 제7조(비보호 저작물)다.

- 사회·과학·영어는 3학년부터 시작하는 교과라 1-2학년군 성취기준이 없다.
- 미포함: 통합교과(바른 생활·슬기로운 생활·건강한 생활·즐거운 생활), 도덕, 실과, 체육, 음악, 미술, 창의적 체험활동.

### JSON 스키마

```json
{
  "meta": { "source": "...", "sourceUrl": "...", "license": "...", "confirmedAt": "...", "coverage": [...] },
  "standards": [
    { "code": "2수01-01", "subject": "수학", "gradeBand": "1-2", "domain": "수와 연산",
      "statement": "수의 필요성을 인식하면서 0과 100까지의 수 개념을 이해하고, 수를 세고 읽고 쓸 수 있다." }
  ]
}
```

- `code`: 대괄호 제거한 성취기준 코드. 첫 자리 2/4/6 = 1-2/3-4/5-6학년군, 이어서 과목 약칭(국·수·사·과·영), 영역 번호, 일련번호.
- `domain`: 별책 2 '성취기준' 절의 영역 표제. 국어 6영역(듣기·말하기/읽기/쓰기/문법/문학/매체), 수학 4영역(수와 연산/변화와 관계/도형과 측정/자료와 가능성), 영어 2영역(이해/표현), 사회·과학은 단원형 표제(예: "우리가 사는 곳", "지구와 바다").
- `statement`: 성취기준 문장 원문(줄바꿈만 이어붙이고 공백 정규화).

## 4. 추출 방법과 검증

추출 스크립트: `tmp/curriculum/extract_standards.py` (tmp는 gitignore — 재수집 시 이 문서 절차로 재구성)

1. NCIC에서 수동 다운로드한 "(2022 개정) …[별책2] 초등학교_국가교육위원회 고시 제2026-1호(2026.1.21.).pdf"를 `pdftotext -layout`으로 텍스트화.
2. 행 시작의 `[2국01-01]`형 코드(사회 일부는 코드 안 하이픈이 en-dash `–`로 조판되어 있어 대시 변형 허용)를 성취기준 문장으로 수집. 같은 코드의 뒤따르는 등장(성취기준 해설·적용 시 고려 사항의 `• [코드]…` 인용)은 첫 등장만 채택하는 방식으로 배제.
3. 문장은 다음 코드/절 표제/불릿/빈 줄 전까지의 연속 행을 이어붙이고, 쪽번호·교과명 머리글 등 조판 잡음 행을 제거.
4. 영역(domain)은 직전의 `(N) 표제` 행에서 취하고, 코드의 영역 번호와 표제 번호 일치(399/399)를 검증.
5. 공백 정규화 1건: `'(자연수)÷ (자연수)'` → `'(자연수) ÷ (자연수)'` (÷ 주변 공백만, 별책 8 수학과 원문 표기 기준. 6수01-10, 6수01-14 두 문장 해당).

검증 결과 (2026-07-07):

- `python3 -m json.tool` 파싱 검증 통과.
- 코드 연속성: 교과×학년군×영역별 일련번호 01부터 결번 없음(전 그룹).
- **판 간 전건 대조**: 2026-1호 통합본 ↔ 2022-33호 원본(경남교육청 재배포 PDF) ↔ NCIC 2022.12판 — 5개 교과 399건의 코드·영역·문장 동일(÷ 공백 조판 차이 2건, NCIC 텍스트 추출 잡음 1건 제외. 모두 문안 차이 아님).
- **무작위 3건 원문 대조** (JSON ↔ 2026-1호 PDF 텍스트, 전문 일치):
  - `2수03-02` (수학 1-2, 도형과 측정): "쌓기나무를 이용하여 여러 가지 입체도형의 모양을 만들고, 그 모양에 대해 위치나 방향을 이용하여 말할 수 있다." — 일치
  - `4과14-02` (과학 3-4, 생물과 환경): "생물 요소들의 먹고 먹히는 관계를 조사하여 먹이그물로 표현할 수 있다." — 일치
  - `4영02-08` (영어 3-4, 표현): "자기 주변 주제에 관한 담화의 주요 정보를 묻거나 답한다." — 일치
- 수학 표본 2건(`2수01-01`, `6수01-10`)은 【별책 8】 수학과 교육과정 PDF와 추가 대조 일치.

## 5. 재수집 절차 (다음 개정 대응)

1. **현행 고시 확인**: https://www.law.go.kr/행정규칙/초ㆍ중등학교교육과정 접속(law.go.kr robots는 `Allow: /`) → 상단 [시행일]·[고시번호] 확인. 별책 재고시 목록은 본문(개정문)과 부칙에 나온다.
2. **별책 PDF 입수**:
   - 1순위: NCIC → 교육과정 자료실 → 교육과정 원문 및 해설서 → 해당 개정시기 → 초등학교(최신판). **반드시 사람이 브라우저로 수동 다운로드** (robots `Disallow: /`).
   - 2순위: 국가교육위원회 ne.go.kr → 자료실 → 법령자료 (고시문 PDF 위주, 별책 전문은 없을 수 있음. robots.txt 미제공 확인됨).
   - 3순위: 시도교육청 재배포 게시판 (예: 경남교육청 gne.go.kr 초등교육과 "2022 개정 교육과정" 게시글 — 별책 1·2 HWP/PDF).
   - 참고: law.go.kr 행정규칙 첨부파일에는 고시문(본문)만 있고 별책 전문은 없다(2026-07-07 확인).
3. 다운로드 파일을 `tmp/curriculum/`에 두고 `pdftotext -layout` → `extract_standards.py` 방식으로 재추출, 본 문서 4절 검증(파싱·건수·결번·무작위 대조)을 반복.
4. 호출 예절: 도메인당 요청 간격 1초 이상, User-Agent 명시, 최소 요청.

## 7. 보조 소스 — KERIS 교과주제별 학습자료 (퀴즈 주제 시드)

성취기준이 "무엇을 배웠나"의 뼈대라면, 실제 퀴즈 소재(주제·키워드)는 KERIS 교과주제별 학습자료로 살을 붙일 수 있다. 성취기준 번들과 라이선스 성격이 다르므로 구분해 둔다.

- data.go.kr KERIS 교과주제별 학습자료 파일데이터(과학·사회·미술 등)는 **이용허락범위 "제한 없음"**(상업 이용 가능). 과학편([15067105](https://www.data.go.kr/data/15067105/fileData.do))을 2026-07-07 실제 다운로드해 검증: CSV 467행, 컬럼 `과목·주제·부제·제목·키워드·바로가기 URL`. 표본 `tmp/curriculum/edunet/`(gitignore).
- odcloud 자동변환 오픈API 제공(swagger `https://infuser.odcloud.kr/oas/docs?namespace=15067105/v1`, `KSKILL_DATAGOKR_KEY`로 활용신청). 통합본으로 KERIS 오픈API "주제별학습자료(에듀넷)"(XML)도 존재.
- 담고 있는 값은 콘텐츠 본문이 아니라 **주제/키워드 메타데이터 + 에듀넷 링크**라, 성취기준 domain과 매칭해 퀴즈 소재 태그·RAG 시드로 쓰기 적합하다.
- 주의: 이름이 비슷한 교육부 PDF 파일데이터([15118987](https://www.data.go.kr/data/15118987/fileData.do))는 전체 1행 링크에 **제4유형(상업 금지)** 이라 다른 자료다. 에듀넷 콘텐츠 API 신청 폼은 **교사 전용**이라 부모/개발자 경로가 아니다.
