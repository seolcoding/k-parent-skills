# 오늘 배운 것 퀴즈

## 핵심 동작

아이의 학교·학년·반을 한 번 등록해 두면, 나이스 시간표에서 그날 배운 과목을 확인하고 학년과 교육과정 성취기준에 맞는 복습 퀴즈를 만들어 부모가 아이에게 바로 읽어줄 수 있는 형태로 출력한다. 안드로이드 앱의 1차 제품 표면으로 설계한다.

## 사용 시점

- "오늘 배운 거 퀴즈 내줘"
- "3학년 수학 복습 문제 만들어줘"
- "오늘 시간표 보고 애랑 복습할 거 뽑아줘"
- "어제 배운 내용으로 문제 5개만"

## 전형적 흐름

### 1. 학교·학년·반 확정

- 학교명으로 학교를 검색해 시도교육청코드와 행정표준코드를 확정한다.
- 해당 학년도 학급 목록에서 학년/반을 고른다.
- 확정된 값은 로컬에 저장해 이후 질의의 기본 키로 재사용한다.

### 2. 오늘 시간표 조회

- 학교급(초/중/고/특수)에 맞는 시간표를 일자 기준으로 조회해 과목 목록을 얻는다.
- 데이터 없음 응답이면 학사일정으로 휴업일/행사일 여부를 먼저 확인하고 그 사실을 알려준다.
- 시간표는 과목명 수준임을 전제로 한다. 단원 수준 정밀화는 학교 공시 평가계획 문서나 부모 입력(교과서·알림장 사진)으로 보강한다.

### 3. 학습 내용 매핑

- 과목×학년(군)을 2022 개정 교육과정 성취기준 번들과 매핑해 이번 학기 학습 내용 후보를 뽑는다.
- 학교알리미 공시의 교과별 평가계획 문서가 있으면 과목별 단원/영역 정보로 우선 사용한다.

### 4. 퀴즈 생성과 출력

- 과목·학년·학습 내용 후보를 바탕으로 아이 수준에 맞는 퀴즈를 만든다. 기본 5문항, 객관식과 단답 혼합.
- 문항마다 정답과 한 줄 해설을 붙인다.
- 아이가 틀린 문항은 비슷한 성취기준으로 재출제할 수 있도록 기록 후보를 남긴다.

## 데이터 소스

- 시간표·학교·학급·학사일정: `packages/k-parent-source-neis` (나이스 교육정보 개방 포털, `KEDU_INFO_KEY`). 엔드포인트 레퍼런스는 docs/neis_api_ref.md.
- 학교 공시·평가계획 문서: 학교알리미 Open API(`SCHOOLINFO_API_KEY`)와 schoolinfo-mcp(MIT, https://github.com/chrisryugj/schoolinfo-mcp)의 평가계획 파싱 도구를 참고 구현으로 사용한다.
- 교육과정 성취기준: 국가교육과정정보센터 자료 기반 로컬 번들(수집 예정).
- 퀴즈 생성 LLM 호출은 proxy 뒤에서 수행하고 키를 클라이언트에 노출하지 않는다.

## 출력 형식

- 아이 학년/반과 대상 과목
- 학교(기관)명과 지역, 시간표 일자
- 확인 기준일과 출처 URL(나이스/학교알리미)
- 퀴즈 문항: 질문, 보기, 정답, 한 줄 해설, 난이도
- 비용: 무료 공개 데이터 기반임을 명시
- 복습 후속 활동 제안(틀린 문항 재출제 등, 별도 준비물 없음)
- 부모의 다음 행동(내일 과목 예고, 재퀴즈 시점)

## 완료 조건

- 오늘(또는 지정 일자) 배운 과목이 시간표 기준으로 확인된다.
- 퀴즈가 과목·학년에 맞고 정답/해설이 포함된다.
- 데이터가 없으면 이유(휴업일, 시간표 미공개)를 설명하고 대안을 제시한다.

## 가드레일

- 아이 이름 등 개인정보는 받지 않는다. 학교/학년/반까지만 사용하고 기기 로컬에 저장한다.
- 시간표·학사일정은 변동 가능하므로 확인 기준일을 함께 표기한다.
- 성적 판단, 또래 비교, 아이를 다그치는 표현을 쓰지 않는다.
