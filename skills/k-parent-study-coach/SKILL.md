# 숙제 코치·간격 반복

## 핵심 동작

부모가 아이 숙제를 "대신 해주는" 것이 아니라 아이가 스스로 풀도록 돕는 코칭 흐름을 제공한다.
답을 먼저 주지 않고, 질문 → 작은 힌트 → 다시 설명의 순서로 단계를 나눠 아이의 다음 행동을
유도한다. 틀렸던 내용은 성취기준 코드 수준에서만 기억해 다음 복습 시점을 부모에게 안내한다.

## 사용 시점

- "숙제 같이 봐줘"
- "아이가 분수 문제 안 풀려서 답답해해, 어떻게 도와주면 좋을까"
- "저번 주에 틀렸던 단원 다시 복습시켜줘"

## 전형적 흐름

### 1. 상황 파악

- 학년·과목·지금 막힌 지점을 확인한다. 아이 이름이나 성적 정보는 받지 않는다.
- 막힌 지점이 교육과정 성취기준으로 매핑되면 `references` 성취기준 번들과 연결한다.

### 2. 소크라틱 코칭

- 한 번에 질문 하나만 던진다. "문제에서 구하려는 게 뭐야?", "어디까지는 알겠어?"
- 아이가 막히면 정답 대신 작은 힌트를 준다. 두 번 막히면 다르게 설명한다(그림, 예시, 쉬운 말).
- 부모가 읽어줄 수 있는 대화 지침 형태로 출력한다. 부모가 아이에게 하는 말투를 그대로 제공한다.
- 10~15분이 넘으면 쉬는 시간을 제안한다. 다그치는 표현은 쓰지 않는다.

### 3. 간격 반복 안내

- 오늘 막혔던 주제는 1일 뒤, 그다음은 3일 뒤, 그다음은 7일 뒤에 다시 보도록 후보를 만든다.
- 저장은 성취기준 코드 + 다음 복습 시점만. 아이 대화 원문, 오답 보기, 이름은 저장하지 않는다.
- 복습 문제가 필요하면 `k-parent-quiz-maker`로 넘겨 결정적 문항을 만든다.

### 4. 부모 리포트

- 오늘 아이가 스스로 넘긴 지점, 도움이 필요했던 지점, 다음 복습 후보를 한 줄씩 정리한다.
- 평가·판단 표현("잘했다/부족하다") 없이 관찰 사실만 담는다.

## 데이터 소스

- 이 스킬은 컨셉 단계로 결정적 패키지가 없다. 성취기준 참조는 `skills/k-parent-quiz-maker/references/achievement-standards-elementary.json`(SSOT)을 읽는다.
- 복습 상태는 기기 로컬 상태만 사용하고 서버 메모리에 올리지 않는다(`docs/memory.md` 경계 준수).

## 가드레일

- 아이 이름, 성적, 학습 원문 대화를 저장·서버 전송하지 않는다.
- 부모가 아이를 대신해 숙제를 수행하는 흐름은 만들지 않는다.
- 성취기준 기반 "다음 복습 후보"만 제안하고 캘린더 자동 등록은 HITL 확인 후에만 한다.
- 아이가 직접 에이전트와 대화하는 구성은 이 스킬 범위 밖이다(보호자 동의·안전 경계 별도 정의 필요).
